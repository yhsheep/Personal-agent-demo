离线演示模式

未配置 Key 时，系统使用本地哈希向量与可预测的 Mock Agent，仍可体验检索、引用与评测流程；适合先本地试用，不必一上来就申请 API。

默认不配置 Key 也能离线体验。需要更自然的回答时，复制 .env.example 为 .env，填入任一国内可用的 OpenAI 兼容服务，然后重启。

终端 
copy .env.example .env
notepad .env
.venv\Scripts\python -m app.cli serve

Embedding 可以用硅基流动 BAAI/bge-m3 或百炼 text-embedding-v4；LLM 可以用 DeepSeek 或通义千问。修改 Embedding 维度后需要重建索引。
